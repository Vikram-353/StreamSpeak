# StreamSpeak

🚀 **StreamSpeak** is a full-stack social media platform built with the **MERN stack (MongoDB, Express, React, Node.js)** along with **TanStack Query** and **Tailwind CSS**.  
It enables **real-time communication** through chat and video calling, while offering a modern UI with **32 customizable themes**.

🔗 **Live Website**: [StreamSpeak on Render](https://streamspeak.onrender.com/login)

---

## 📌 Features

- 💬 **Real-time Chat** – Fast and reliable messaging system.  
- 📹 **Video Calling** – One-on-one video communication.  
- 👫 **Friends System** – Send, receive, and manage friend requests.  
- 🎨 **Customizable Themes** – 32 UI themes to personalize the experience.  
- 📷 **Media Sharing** – Optimized image & video sharing with **<1s load time**.  
- ✅ **Tested APIs** – 20+ API tests ensure platform reliability.  
- ⚡ **Performance Focused** – Designed for **200+ active users** with smooth performance.  

---

## 🛠️ Tech Stack

- **Frontend**: React.js, TanStack Query, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Others**: WebRTC (video calls), Axios, REST APIs
